# Site du Cercle Triathlon Toulouse

Site statique publié sur GitHub Pages, domaine cercletriathlontoulouse.fr (DNS chez OVH).

- `index.html` contient toute la page (styles et scripts inclus)
- `images/` contient photos et logos
- Actualités Instagram via un flux JSON Behold, identifiant à renseigner dans l'attribut `data-flux` de `#flux`
